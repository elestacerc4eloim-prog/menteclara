1. Sube el index.html nuevo dentro de esta carpeta test/
2. Abrelo en el celular con la URL de arriba
3. Revisa que carguen: Inicio, Comunidad, Pueblos, Planes, Chat
4. Cierra y reabre para ver si mantiene la sesion
5. Si todo funciona, recien entonces subelo al index.html principal
